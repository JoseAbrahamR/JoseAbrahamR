#### Proyecto: Sistema de Gestión de Prácticas Pedagógicas (UBB)
Plataforma web Full Stack orientada a digitalizar el seguimiento y evaluación de prácticas docentes:
* **Arquitectura y Persistencia:** Desarrollada con Java, Spring Boot, Spring Data JPA, Thymeleaf y MySQL.
* **Funcionalidades Clave:** Módulo de revisión y calificación de informes finales, asistente de IA para revisión de planificaciones, dictado por voz y control de acceso basado en roles.
* **Calidad y Flujo Colaborativo:** Pruebas unitarias automatizadas con JUnit 5 y Mockito.
